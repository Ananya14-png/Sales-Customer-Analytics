# Sales & Customer Analytics

## 📊 Project Overview

A data analytics project focused on analyzing sales performance, customer behavior, product performance, and profitability using SQL and Power BI.

The project covers data preparation, SQL-based analysis, and interactive dashboard development to generate meaningful business insights.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Understand customer purchasing behavior
- Identify high-performing products and categories
- Analyze sales and profitability by category and sub-category
- Calculate key business metrics
- Build interactive Power BI dashboards
- Present insights in a clear and business-friendly format

## 🛠️ Tools & Technologies

- SQL
- MySQL
- Power BI
- Microsoft Excel
- Python
- Pandas
- Data Visualization

## 🗄️ SQL Analysis

SQL queries were used to calculate and analyze key business metrics, including:

- Total Sales
- Total Profit
- Total Quantity
- Unique Customers
- Unique Orders
- Average Order Value
- Category-level sales and profit
- Sub-category-level sales and profit
- Profit margin

The SQL queries are available in:

`sql/sales_customer_analysis.sql`
